**Nova Domains Count** — это бесплатное расширение для Chromium-браузеров (Chrome, Edge, Brave и др.) с открытым исходным кодом, предназначенное для мониторинга всей сетевой активности на веб-страницах.

## Основные возможности

- Мгновенный перехват запросов: Фиксирует обращения через `webRequest.onBeforeRequest` сразу в момент отправки, не дожидаясь ответа сервера.
- Статистика отдельно по каждой вкладке: Данные собираются для активной вкладки и не смешиваются между разными страницами.
- Более точный сбор доменов: Учитываются запросы из `iframe`, `worker` и связанных контекстов страницы, поэтому сторонние домены не пропадают после загрузки.
- Режимы `ROOT` и `ALL`: В режиме `ROOT` поддомены объединяются до корневого домена, например `element.io`. В режиме `ALL` отображаются полные имена доменов, например `app.element.io`.
- Обновления в реальном времени: получает актуальные данные от фонового `service worker` почти сразу после появления новых запросов.
- Подсчет обращений: Для каждого домена отображается количество запросов, что помогает быстро увидеть наиболее активные источники трафика.
- Индикация локальных адресов: Если запросы к домену идут через локальный адрес, например `127.0.0.1`, `localhost` или `192.168.x.x`, адрес показывается под доменом.
- Быстрое копирование: Можно скопировать весь текущий список доменов или отдельный домен из строки.
- Темная и светлая тема: Переключение темы сохраняется между открытиями Popup.
- Компактный интерфейс: Только домены, счетчики, локальные адреса и быстрые управляющие кнопки без лишних элементов.


## Установка

1.  Скачайте актуальный архив (например Nova_Domains_Count_v1.5.0.zip) из [релиза](https://github.com/confeden/Nova-Domains-Count/releases).
2.  Распакуйте архив в удобное место.
3.  Перейдите в `chrome://extensions/`.
4.  Включите **"Режим разработчика"** (Developer mode).
5.  Нажмите **"Загрузить распакованное расширение"** (Load unpacked) и выберите распакованную папку , в которой лежит `manifest.json`.

## Безопасность и Конфиденциальность

Расширение работает полностью локально в вашем браузере. Оно не собирает, не хранит и не передает никакие данные на внешние серверы. Весь подсчёт доменов происходит внутри контекста страницы для отображения статистики в Popup-окне.
